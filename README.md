# DOW

公开代码项目仓库。

当前仓库包含独立代码项目，例如 `codex-bark-watch/`、`wb-guard/`。本仓库用于保存适合公开发布的代码与配套文档，不作为 Ashy 的工作资料、记忆或公司内部文档归档位置。

## 仓库边界

允许提交：

- 可公开的软件源码
- 项目 README、使用说明与公开技术文档
- 与公开项目直接相关的配置模板

禁止提交：

- 公司内部工作资料或财务资料
- ChatGPT / WorkBuddy 长期记忆文件
- 密码、Token、API Key、Cookie 或登录态
- 含个人隐私、员工信息或未脱敏业务数据的文件
